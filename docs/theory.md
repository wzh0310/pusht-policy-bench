# 理论笔记：BC 的缺陷与进阶方向

## 1. 分布偏移（distribution shift）与误差累积

### 问题的根源

BC 的训练假设是：训练时和测试时的状态分布相同，都来自专家轨迹的分布 $d^{\pi^*}$。
但部署时策略看到的是**自己上一步造成的后果**：$s_{t+1} \sim P(s_{t+1} | s_t, \hat a_t)$，
其中 $\hat a_t = \pi(s_t)$ 是网络预测的动作。一旦 $\hat a_t$ 与专家动作 $a^*_t$ 有偏差，
系统就会进入专家从未访问过的状态——网络在这些状态上的输出是**未经训练的**，
误差被进一步放大。这就是复合误差（compounding error）。

### 数学解释（Ross et al., 2011, "A Reduction of Imitation Learning..."）

定义 $\ell_t$ 为第 $t$ 步策略 cost（与专家动作的偏差）。关键结论：

> 在总变异散度（TV divergence）意义下，若单步模仿误差为 $\epsilon$，
> 则 $T$ 步 rollout 的期望 cost 上界为 $O(T^2 \epsilon)$。

直觉推导：第 $t$ 步的策略表现，取决于前面 $t-1$ 步每一步都"没跑偏"。
每一步以概率 $\epsilon$ 进入训练分布外状态，而训练分布外状态下误差可能达到常数级，
于是 $\sum_{t=1}^{T} t\epsilon = O(T^2\epsilon)$。
对比 RL 里逐环境交互修正的策略，其上界是 $O(T\epsilon)$。
**平方级放大是 BC 的天花板**：轨迹越长、动作维度越高，越容易被放大到任务失败。

PushT 任务上这个效应的具体表现：夹爪位置偏差几个像素 → 推块角度偏了几度 →
之后需要专家从未演示过的修正轨迹 → 策略开始无意义抖动（见失败录像）。

### 缓解思路（不改动算法的前提下）

- **缩短决策时域**：误差 $O(T^2\epsilon)$ 里 $T$ 是 rollout 长度；闭环高频控制 +
  短 episode 任务天然有利；
- **动作分块（action chunking）**：一次预测未来 $k$ 步动作并依次执行，
  等效于把单步决策换成开环片段，减少每步独立出错的次数（ACT 的核心动机之一）；
- **数据覆盖度**：让训练分布尽量宽（随机初始位姿、扰动注入），
  $\epsilon$ 在分布边缘也不至于爆炸。

## 2. DAgger：在线纠偏

**核心思想**：把部署时遇到的"新状态"送回去给专家标注，加入训练集，迭代循环。

```
初始化 D ← 专家演示数据
循环:
  1. 用当前策略 π_i rollout，记录访问到的状态（不要专家动作）
  2. 专家在这些状态上补标动作：D ← D ∪ {(s, a*)}
  3. 在 D 上重新训练 π_{i+1}
```

为什么有效：每轮迭代把"策略实际会到达的状态"拉进训练分布，
用聚合（aggregation）消除 train/test 分布差。理论保证收敛到
与专家策略在**自己访问的分布**上损失 $\le \epsilon$ 的策略，
$O(T^2\epsilon)$ 退化为 $O(T\epsilon)$。

代价：需要专家在线、可查询——真实机器人上的人工成本很高，
这催生了 DART（注入扰动代替纠偏）、HG-DAgger（人监督纠正）等变体。

## 3. ACT 论文解读（"Learning Fine-Grained Bimanual Manipulation..."，Zhao et al. 2023）

**一句话**：把 BC 的"单步动作回归"升级为"CVAE + Transformer 的动作块预测 + 时间集成"。

三个组件分别解决一个 BC 的痛点：

| 组件 | 解决的问题 |
|---|---|
| 动作块（chunk）：一次回归未来 $k$ 步动作 | 降低单步决策频率 → 压制 $O(T^2\epsilon)$ 累积 |
| CVAE 动作头：latent $z$ 建模多模态 | MSE 回归在多模态演示下输出"平均动作"（动作模糊） |
| 时间集成（temporal ensemble）：重叠块加权平均 | 块与块之间边界不连续 |

**为什么用 Transformer 做序列预测**：动作块本质是一个长度 $k$ 的序列回归问题，
自注意力比 RNN/MLP 更擅长并行地建模块内步与步之间的依赖，
且与 ViT 视觉编码器结构统一（ACT 用小型 ViT 做图像编码）。

## 4. 结合 RL 背景：BC 与离线 RL 的区别与联系

| 维度 | BC | 离线 RL |
|---|---|---|
| 学习信号 | 监督（演示动作） | 贝尔曼备份（离线轨迹的奖励） |
| 数据要求 | 需要动作标签（专家演示） | 只需 (s, a, r, s') 轨迹 |
| 动作空间约束 | 无约束，回归/分类任意动作 | 必须显式处理 OOD 动作（Q 高估） |
| 优化目标 | 单步似然/回归误差 | 累计回报（需处理分布偏移 + bootstrap 偏差） |
| 上限 | 不超过演示者（在演示分布上） | 可能超过演示者（利用奖励信息组合出新行为） |

联系：两者都是**离线**学习，都面临分布偏移；BC 可以看成忽略奖励的离线 RL 特例。
实践中的经验法则：先做 BC 建立下限，离线 RL 连 BC 都打不过时优先怀疑数据或实现；
BC + 小的奖励微调（RL fine-tuning）常是性价比最高的组合。
